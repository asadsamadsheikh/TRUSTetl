ABOUT THE PROJECT

Why TrustETL?

TrustETL explores a multi-agent approach to more trustworthy automated ETL.

The research idea

A Coder Agent proposes a transformation. Instead of trusting that first answer, an independent Critic Agent actively searches for weaknesses. Failed checks trigger revision, and a Validator Agent performs a final independent verification.

ARCHITECTURE

Three agents, separate responsibilities.

C

Coder Agent

Generates the proposed cleaning and transformation workflow.

X

Critic Agent

Attempts to expose logical, statistical, and data-quality problems.

V

Validator Agent

Checks whether the final output satisfies the required validation rules.

Core research gap

Existing approaches can automate data cleaning or use self-feedback, but TrustETL focuses on adversarial critique between separate agent roles followed by independent validation.
